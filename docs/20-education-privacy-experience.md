# 教育内容与隐私体验实现说明

本批次只使用合成演示数据，未接入真实学生资料。筛查信息仍然是支持安排的初步线索，不等于医学诊断。

## 学生端教育内容

- `/v1/content/public` 支持 `age`、`kind` 和教育主题 `category` 筛选；页面提供搜索、资源类型、主题、适龄和已读/收藏筛选。
- 内容管理草稿增加身心健康、情绪、压力、关系、睡眠、求助等主题分类。默认分类为 `general`，旧内容无需重写即可继续展示。
- 学生的已读/收藏保存到独立的 `content_engagements` 集合，只保留内容 ID、时间和状态，不保存阅读正文、停留时长或画像；下架和依法删除主体资料时一并清理。
- 音视频可以绑定已扫描的 WebVTT 字幕文件，也必须有字幕文件或文字稿才能发布。学生播放器提供可切换字幕和可展开文字稿；图片仍要求文字替代。

## 统计抑制说明

统计 API 返回 `suppressionThreshold` 和面向工作人员的解释文案。样本不足 10 时返回 `null`/“已抑制”，页面明确说明这表示样本不足，不表示 0 人或没有风险，也不代表疾病患病率；不会用说明文字反推出被抑制的具体人数。

## 数据访问与权利申请

- 学生端 `/v1/me/data-access-history` 只返回本人主体 ID 对应的、有明确用途的反馈查看、授权档案和最小必要个案背景事件；不返回对象 ID、原始正文、答卷、危机理由或其他学生的事件。
- 专业查看报告、个案队列或授权档案时，服务端追加面向主体的审计事件；查看者只以显示名和必要角色标签呈现。
- 权利申请卡片显示提交时间、当前状态、下一步说明和完成时间；完成或拒绝后仍通过既有结果接口读取处理结果。

## 面部微表情/视觉互动边界

视觉互动不是测评、危机判断、预警或人员排名的一部分。部署默认关闭；只有已批准的独立视觉用途告知版本和学生明确同意后，才请求摄像头权限。浏览器模块只创建本地预览和中性动画：不调用网络发送 API，不上传或保存视频、照片、面部关键点，不输出情绪、风险或诊断标签。停止、页面隐藏、离开页面和三分钟上限都会释放摄像头轨道，核心测评与表达功能不依赖它。
