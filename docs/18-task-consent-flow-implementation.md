# 任务内分用途同意流程

## 行为

- 学生首次打开测评任务时，在任务卡内查看本次用途、谁能查看、适龄范围、预计用时和当前告知版本；同意表单和版本历史都位于该任务卡，不再使用独立“测评参与说明”页面。
- 自选筛查在相应方案卡中说明并取得测评用途同意。告知版本变化时旧记录保留为历史版本，新同意建立独立记录。
- 表达与视觉互动分别展示说明、受众/保存信息、独立版本历史、撤回和重新同意控件。撤回一种用途不会自动撤回其他用途。
- 学生可查看自己的年龄段、未成年人状态和监护核验状态。14 岁以下须由已核验监护人逐用途确认；14–17 岁由学生本人作出用途决定。监护人账号只可处理已核验关系，且只收到当前任务/告知元数据，不会取得答卷、报告或自述正文。
- 撤回沿用现有服务端用途副作用：测评撤回会停止相关测评处理；表达/视觉互动撤回分别停用各自处理。再次同意不会恢复先前分享、已删除记录或已取消请求。

## 保留期限说明与限制

- 测评正式保留期限在当前仓库/演示策略中**尚未配置或审批**。界面明确展示此状态、禁止暗示虚构的具体期限，并提示不得提交真实个人信息；生产上线前必须由学校隐私负责人确定具体期限并纳入获批告知版本。
- 表达用途使用已配置的演示策略：本人记录到期清理天数、关闭支持请求保留天数；当前值是合成演示配置，不等同生产合规批准。分享仅对学生所选支持人员在有效期内开放。
- 视觉互动默认关闭；启用后仍先取得单独的业务同意及浏览器摄像头权限。实现只进行本地中性界面互动，不上传或持久化视频、照片、面部特征或情绪推断；视觉同意记录的正式保留期限仍需学校配置。
- 同意历史当前列出用途、告知版本号、记录主体、记录时间、状态和撤回时间。历史文本是否需法律审计级别的不可变副本仍须上线前由隐私/法律负责人确认。

## 验证范围

通过合成数据回归验证：14 岁以下本人不能代替监护人同意；监护人未核验前不能作出同意；已核验监护人只获得最小任务元数据；各用途状态互不影响；历史状态可见且可按用途撤回。无真实学生信息、外部通知或生产部署。
