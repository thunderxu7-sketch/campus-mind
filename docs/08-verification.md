# 测试与试点验收

## 1. 当前仓库已经验证与尚未验证的边界

仓库包含合成数据参考实现。当前 CI/本地已验证：TypeScript 构建、48 项 Node 行为/安全测试（含加密私有对象存储、媒体指针、无手机学生凭证、会话撤销、会话过期、审计视图、内容草稿权限与密文隔离、内容下架、密钥轮换、登录限流、服务端适龄/任务可用性、撤回/到期量表不可用性、导出用途/水印、导出审批分离、撤回报告后导出失效、专业结案申请人与审批人分离、授权到期阻断、预约排班范围/占用保护/幂等重试、学生反馈与主体权利申请列表、以及答题窗口/频次二次校验）、12 项规划校验器测试、依赖审计、敏感资料扫描，以及 PostgreSQL 参考迁移的干净服务重复执行（36 张表启用并强制 RLS，CI 含 PostgreSQL 16 服务，并检查应用角色无 `SUPERUSER/BYPASSRLS` 且不能修改审计表，并用合成双租户插入验证复合外键拒绝串租户引用，且验证审计表 UPDATE/DELETE 触发追加写保护）。**这些证据不等于生产性能、临床有效性、法律合规或真实值班能力。**

`npm run check` 会运行构建、行为测试、安全扫描和规划校验；`npm audit --omit=dev --audit-level=high` 单独检查依赖。对象存储测试验证租户派生加密、哈希寻址、路径穿越拒绝、大小上限、0600 文件和媒体发布指针。`npm run drill:recovery` 还会复制并校验本地合成加密对象，`npm run drill:crisis` 演练线索投递、人工接续、独立结案和死信修复，`npm run drill:key-rotation` 验证字段与对象旧密钥读取、使用当前密钥重加密及移除旧密钥后的拒绝，`npm run drill:capacity` 生成有并发、p50/p95、错误率的本地基线；`npm run release:check` 在参考模式检查仓库边界，生产模式会因缺少外部签署证据而阻断；`POST /v1/admin/retention/run` 可在恢复后重放删除台账并使过期导出失效。迁移仍需在目标数据平面由独立迁移身份执行并完成双租户/运行角色验证。

生产入口若未注入 PostgreSQL-backed store 会直接拒绝启动；`CAMPMIND_POSTGRES_ADAPTER_READY=true` 只应在真实适配器、连接池租户上下文和 RLS 演练完成后设置。

下列检查全部是未来实施后的验收要求，不能因为已写进此文就标记通过。

## 3. 计分专项

计分包不依赖数据库或网络；相同输入及版本输出稳定。除正确样例，还覆盖最小/最大值、所有反向题、因子交叠、舍入策略、缺题阈值、无效项、题目 ID 越界、版本错配。专业复核签署样例与解释文案；算法升级跑新旧版本差分，历史结果不被覆写。

模拟量表测试只能验证工程机制，不证明真实量表信效度。真实适龄证据、版权和临床阈值必须独立审查。

## 4. 风险专项桌面演练

由专业负责人主持以下情境：高优先级线索、低分但主动求助、误报、未完成测评求助、工作人员失联、通知通道故障、夜间访问、疑似家庭侵害、转介无人回执、再次出现线索。记录每步操作者、实际耗时、升级路径及失败点，确认页面承诺与实际值班匹配。

## 5. 真实试点 Gate（全部通过才可开始）

- [ ] M0 需求与责任签字；学校、服务方、专业负责人及隐私角色明确。
- [ ] 首个方案的授权、适龄/常模、施测条件、独立计分与报告解释通过专业审查。
- [ ] 名单采集依据、告知、所需同意、监护核验、频次、保存期、权利渠道明确并实现。
- [ ] 身份/租户/对象/字段/文件/导出隔离验收通过，无未处置的严重权限缺陷。
- [ ] 专业值班、备用、接单和升级时限以及校方应急流程已演练；真实联系方式已核实。
- [ ] 灰度开关、停止新增测评、人工接续、备份恢复、撤回删除重放与回滚通过演练。
- [ ] 日志、通知、GitHub、测试报告未包含真实敏感资料；供应商与数据位置通过审查。
- [ ] 所有 P0，以及 M4 纳入的基础统计/导出等 P1 验收；未验证项不得写成通过。
- [ ] 校方受控试点批准，明确人数/学段/窗口/反馈渠道与停止条件，不擅自全校扩张。

## 6. 停止条件

发生疑似资料泄漏、跨租户访问、计分错误导致错误解释、严重线索无承接、导出/通知泄漏、学生受强制参与、关键许可/专业资格失效时，暂停新增真实测评，保护在途数据并由校方专业人员接管支持。按事件流程处置和复盘，未经复核不能靠回滚代码直接恢复。
